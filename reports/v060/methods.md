# Methods and limits

The initial DNA branch has 2,409,641 parameters, down from 7,949,052 in v0.55 (69.7% fewer). It uses six192-channel residual blocks with dilations1/2/8/32/128/512, retains3/4/5/6-mer features, and removes the motif path, short-scale experts, parent512 shared projection and old dual heads. The unchanged adapted NTv3 100M and ESM-C300M branches remain. A600-round depth6 tree fuses standardized1920-dimensional protein features, the raw DNA logit, true log10length and protein-probe logit; NT logit weight is0.75. No model-size-only causal claim is made.

Supervised expanded fitting uses1,708,227 fragments/9,757species,1–100kb, current known contamination exclusions and zero canonical species overlap with the four evaluation panels. Genomes used for supervised Train/Validation predate2026-01-01. This does not clear contamination exposure in ancestor models or unknown foundation-model pretraining overlap. Historical former-Final development reuse remains disclosed in model metadata; zero new originalFinal/New934 reads in this iteration is not a never-exposed lineage claim.

Five species-fold out-of-fold Validation predictions select one of25 predefined two-slope length transforms; exact global F1@1% threshold is then frozen. True length is clipped1–10kb for this smooth score transform. Both slopes are-1. Final comparison uses one global strict threshold for all lengths and reports0.1%,1%,10% prevalence. Overall F1 pools counts; it is not a mean of bin F1. Candidate choice considered completed base, continuation, fusion and calibration alternatives on reused development panels.

The initial DNA branch uses a single central100kb crop only when the contig exceeds100kb, while final fusion retains true contig length. Inputs <=100kb are unchanged. Long-input scoring was smoke-tested beyond1Mb; classification accuracy above100kb was not validated. Separate10/50/100kb experiments on the originalBCE fusion found that10kb added3long-panelFN and50kb retained aggregateF1, but those results do not establish an interchangeable50kb budget for the final fusion.

DNA<=0.01 can skip ORF extraction and both language models. An unguarded prototype was rejected after completeValidation showed14label changes despite passing a small canary. The released candidate uses a Validation-informed guard: if any final buffer score lies within2logit units of the threshold, recompute the complete original buffer without exits. Exact original buffer composition is restored; no sequence is dropped. Guarded labels matched full inference on the registered RTX4090 panels. Scores change and this is not a mathematical or cross-hardware invariance guarantee. --full-esm disables confidence exits and the associated fallback, while retaining the DNA input budget.

Main and supplementary false negatives can increase while false positives decrease; low-prevalenceF1 can consequently improve. The target ofF1>=0.99 in every500bp interval remains unmet. Confidence intervals are conditional on the fixed models and reused panels, not corrected for historical adaptive search. Decision scores are not guaranteed posterior probabilities at arbitrary sample prevalence.
